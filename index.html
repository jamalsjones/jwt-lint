Access tokens · RFC 7519 · 8725 · 9068

Paste an access token and see what an API should reject it for. Everything runs in this page; the token isn't sent anywhere.

Token

The signature isn't verified. That needs the issuer's key and is your API's job, so a token can pass here and still be forged.

Findings

Paste a token, or try a sample.

In a pipeline

The same file is a command-line tool. It exits 1 when it finds errors, so it can fail a build or a smoke test.

node jwt-lint.js "$TOKEN" --aud https://api.example.com --iss https://login.example.com --alg RS256
